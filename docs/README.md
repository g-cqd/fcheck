# Using fcheck

fcheck checks that Swift code keeps its obligations on every path out of a function.

- [Rules](rules.md): the three obligations it checks, an example, and its limits.
- [Configuration](configuration.md): rules, your own resources, suppression.

Options, baselines, exit codes and reports work as in the other analyzers; see
[how the analyzers behave](https://github.com/g-cqd/analyzerkit/blob/main/docs/analyzer-contract.md).
